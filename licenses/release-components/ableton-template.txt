Groove Pizza modifications: remove original notes, device chains, samples,
file references, return tracks and stored view data; replace musical content,
tempo, gain, scenes and loop lengths with validated current groove data.
No original instrument presets, sound recordings or sample packs are bundled.
The generated sets are experimental and have not yet been validated in Live.
This is not Ableton's official Live Set Export SDK or an endorsed integration.
